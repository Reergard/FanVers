# Захист від ботів (fail2ban)

## Навіщо це

На сервер постійно ломляться боти — намагаються вгадати пароль до SSH (`Invalid user kali from ...`, `Connection closed by authenticating user root ...`). Без захисту вони можуть підібрати слабкий пароль або просто завалити сервер запитами.

`fail2ban` — це сторож на дверях. Він читає логи SSH, рахує невдалі спроби з кожної IP-адреси, і коли спроб забагато — додає правило у файрвол, яке блокує цю IP на певний час.

## Що захищено

Поки що — **тільки SSH** (вхід на сервер через термінал). Вебсайт у nginx, API в Django мають свій throttling — це окрема історія.

## Де працює

Тільки на **продакшен-сервері** (Contabo). На локалці (Windows) не потрібно — вона не дивиться в інтернет.

## Як було встановлено

```bash
sudo apt update
sudo apt install -y fail2ban
sudo systemctl enable --now fail2ban
```

`enable --now` робить дві речі: вмикає автозапуск при перезавантаженні сервера + запускає сервіс прямо зараз.

## Конфігурація

Файл: `/etc/fail2ban/jail.local`

```ini
[DEFAULT]
bantime = 30m
maxretry = 6
findtime = 10m
ignoreip = 127.0.0.1/8 ::1 194.212.104.104

[sshd]
enabled = true
port    = ssh
```

### Що означає кожен параметр

- **`bantime = 30m`** — IP блокується на 30 хвилин. Для бота болюче (треба чекати), людина за цей час згадає пароль або відновить доступ.
- **`maxretry = 6`** — дозволено 6 невдалих спроб логіну. Жива людина встигне 5-6 разів спробувати.
- **`findtime = 10m`** — рахуємо спроби тільки за останні 10 хвилин. Тобто 6 спроб за 10 хвилин = бан. 6 спроб за добу — нічого не буде.
- **`ignoreip`** — список IP, які **ніколи не банимо**:
  - `127.0.0.1/8` — сам сервер (loopback).
  - `::1` — IPv6 loopback.
  - `194.212.104.104` — мій домашній IP. **Якщо зміниться — оновити!**

### Чому не суворіше

Боти ломляться 50-100 раз за секунду — вони все одно влетять у `maxretry=6` за 0.1с. М'які налаштування для людей не послаблюють захист від ботів, бо боти швидкі.

## Як перевірити, що працює

```bash
sudo systemctl status fail2ban           # має бути active (running)
sudo fail2ban-client status              # список jail-ів
sudo fail2ban-client status sshd         # статус sshd-jail: скільки IP заблоковано зараз
```

Через якийсь час `status sshd` покаже список заблокованих IP — це нормально, боти безперервно ломляться.

## ⚠️ ЯК РОЗБЛОКУВАТИ КОРИСТУВАЧА (ВАЖЛИВО)

Якщо хтось випадково потрапив у бан (забув пароль, перебирав логіни, тощо) — розблокувати можна однією командою:

```bash
sudo fail2ban-client set sshd unbanip 1.2.3.4
```

Замість `1.2.3.4` поставити реальну IP-адресу користувача.

### Як дізнатися IP, який заблоковано

```bash
sudo fail2ban-client status sshd
```

Вивід міститиме рядок `Banned IP list:` зі списком IP. Звідти беремо потрібну.

### Альтернативно — переглянути лог fail2ban

```bash
sudo tail -50 /var/log/fail2ban.log
```

Покаже хронологію банів і автоматичних розбанів.

## Як змінити конфігурацію

1. Редагувати `/etc/fail2ban/jail.local`:
   ```bash
   sudo nano /etc/fail2ban/jail.local
   ```
2. Зберегти (Ctrl+O, Enter, Ctrl+X).
3. Перезапустити:
   ```bash
   sudo systemctl restart fail2ban
   ```
4. Перевірити, що піднявся:
   ```bash
   sudo systemctl status fail2ban
   sudo fail2ban-client status sshd
   ```

## Коли можуть видалитися налаштування

`fail2ban` — системний пакет Ubuntu. Він **не зникає** при:
- `git pull` проекту.
- `npm install` / `pip install` залежностей.
- Перезапуску бекенду / nginx / daphne.
- Перезавантаженні сервера.

Зникнути може тільки якщо:
- Вручну зробити `sudo apt remove fail2ban`.
- Перевстановити OS на сервері (Contabo OS reinstall) — тоді ставити заново.

## Якщо випадково заблокував сам себе (свій IP)

Якщо домашній IP змінився і вже забанили:

1. Зайти на сервер через **VNC-консоль панелі Contabo** (не через SSH — він тебе не пустить).
2. Виконати:
   ```bash
   sudo fail2ban-client set sshd unbanip <твій_новий_IP>
   ```
3. Додати новий IP у `ignoreip`:
   ```bash
   sudo nano /etc/fail2ban/jail.local
   # додати IP до рядка ignoreip
   sudo systemctl restart fail2ban
   ```

## Файли

- `/etc/fail2ban/jail.local` — наша конфігурація (редагуємо тільки її).
- `/etc/fail2ban/jail.conf` — дефолтна конфігурація пакета (не чіпати, оновлюється при `apt upgrade`).
- `/var/log/fail2ban.log` — лог банів і розбанів.
- `/var/log/auth.log` — лог самого SSH (звідки fail2ban читає невдалі спроби).
