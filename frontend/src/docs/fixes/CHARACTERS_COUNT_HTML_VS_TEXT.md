# ВІДКРИТА ПРОБЛЕМА — Підрахунок символів: HTML-розмітка vs чистий текст

**Статус:** рішення НЕ прийнято. Чекаємо фіналізації методу завантаження/зберігання глав.

---

## Суть проблеми

Система рахує `len(html_content)` — тобто довжину HTML-рядка включно з тегами розмітки.
Mammoth при конвертації `.docx` генерує HTML, і теги (`<p>`, `</p>`, `<strong>` тощо) потрапляють у підрахунок.

**Реальний тест (Розділ 4.docx):**

| Джерело | Значення | Що рахується |
|---------|----------|--------------|
| Word — Знаків (з пробілами) | **7 588** | Чистий текст + пробіли |
| Word — Знаків (без пробілів) | **6 372** | Лише символи |
| Система (поточна) | **8 420** | `len(html_content)` — текст + HTML-теги |

Різниця 8 420 − 7 588 = **832 символи** — це теги.
При 74 абзацах (з файлу) тільки `<p></p>` дають ≈518 зайвих символів, решта — теги форматування.

---

## Два варіанти рішення

### Варіант А — Залишити як є (`len(html_content)`)
Нічого не змінювати. Переводчику "вигідніше" — до порогів комісії (5 млн / 10 млн) доходить швидше.

### Варіант Б — Рахувати тільки чистий текст
Перед підрахунком стрипати HTML-теги. Результат збігатиметься з Word «Знаків (з пробілами)».

**Файли для зміни:** `backend/apps/catalog/models.py`
- Метод `Chapter.save()` — блок `if self.html_content:`
- Метод `Chapter.save_html_content(html_content)`

**Формула:**
```python
import re
clean_text = re.sub(r'<[^>]+>', '', html_content)
self.characters_count = len(clean_text)
self.character_count = len(clean_text)
```

---

## Що НЕ змінювати до прийняття рішення

- `Chapter.save()` — поля `characters_count`, `character_count`, `reading_time`, `min_reading_time`
- `Chapter.save_html_content()` — ті самі поля
- `Profile.total_characters` — хранимий накопичений підсумок
- Сигнали `pre_save / post_save / post_delete` для Chapter

---

## Вплив рішення на систему

При зміні на Варіант Б всі **існуючі** значення `characters_count` у БД стануть завищеними.
Потрібно буде запустити:
```bash
python manage.py sync_total_characters
```
Ця команда перерахує `Profile.total_characters` і `commission` для всіх профілів з актуальних даних глав.
