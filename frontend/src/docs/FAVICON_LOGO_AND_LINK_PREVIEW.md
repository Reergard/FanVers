# Иконка вкладки, лого в поиске и карточка ссылки

Коротко: что есть сейчас и что делать, если починить.

---

## Общая картина (2 минуты на чтение)

Сайт — это React-приложение. Браузер пользователя всё рисует сам.

Но когда человек **кидает ссылку в Telegram, Instagram, Facebook** — тот сервис **не открывает сайт как браузер**. Он один раз скачивает HTML-страницу и ищет там:
- заголовок
- описание
- картинку

Для этого у нас есть **два пути**:

| Кто открывает | Что видит | Кто это настраивает |
|---------------|-----------|---------------------|
| Человек в Chrome/Firefox | React + вкладка с названием | Фронтенд (`frontend/`) |
| Telegram, Google-бот, Facebook | Готовая HTML-страница от Django | Бэкенд (`backend/apps/seo/`) |

**Важно:** на сервере (nginx) ботов нужно направлять на Django, иначе они получат пустую страницу. Пример настройки: `backend/apps/seo/nginx_seo.conf.example`.

## 1. Иконка вкладки (favicon)

Маленькая картинка слева от названия вкладки в браузере.

### Состояние сейчас

- **Нет.** Во вкладке везде дефолтная иконка браузера.
- В `frontend/index.html` нет строк `<link rel="icon" ...>`.
- В папке `frontend/public/` нет файлов favicon — только `sprite.svg` и `sprite-book.svg`.
- Лого в шапке сайта (`frontend/src/assets/logos/logo.png`) — это **другое**. Оно внутри приложения, вкладка его не использует.

### Можно ли сделать?

**Да.** Простая задача, 1–2 часа с подготовкой картинок.

### Варианты

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| **A. Полный набор иконок** (рекомендуется) | Работает везде: Chrome, Safari, Android «на экран» | Нужно нарезать 6–7 размеров из логотипа |
| **B. Только один файл `favicon.ico`** | Быстро, один файл | На Retina может быть мыло; iPhone «на экран» без красивой иконки |
| **C. Только SVG** | Один файл, чётко на любом экране | Старые Safari/некоторые места SVG не любят |

### Где и как делать

1. **Подготовить картинки** из логотипа FanVers (можно через [realfavicongenerator.net](https://realfavicongenerator.net) — загрузить `logo.png`, скачать архив).
2. **Положить файлы** в `frontend/public/`:
   - `favicon.ico`
   - `favicon.svg`
   - `favicon-16x16.png`
   - `favicon-32x32.png`
   - `apple-touch-icon.png` (180×180)
   - `android-chrome-192x192.png`
   - `android-chrome-512x512.png`
3. **Создать** `frontend/public/site.webmanifest` (имя сайта + ссылки на android-иконки).
4. **Добавить в** `frontend/index.html` внутрь `<head>`:
   ```html
   <link rel="icon" type="image/svg+xml" href="/favicon.svg">
   <link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
   <link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
   <link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
   <link rel="manifest" href="/site.webmanifest">
   <meta name="theme-color" content="#1a1a2e">
   ```
   Цвет `#1a1a2e` — подставить реальный основной цвет сайта из CSS.
5. **Задеплоить** фронтенд.
6. **Проверить:** открыть сайт → посмотреть вкладку. Жёсткое обновление: Ctrl+Shift+R. Или [realfavicongenerator.net/favicon_checker](https://realfavicongenerator.net/favicon_checker).

### Что нужно для починки

- Исходник логотипа (есть: `frontend/src/assets/logos/logo.png`)
- Доступ к деплою фронтенда
- Ничего на бэкенде менять не нужно

## 2. Лого / иконка сайта в Google и Bing

В результатах поиска слева от адреса сайта — маленькая иконка. Заголовок и текст под ней.

### Состояние сейчас

- **Иконка в поиске:** скорее всего пустая/стандартная — потому что **нет favicon** (см. раздел 1). Google берёт favicon с корня сайта.
- **Заголовок и описание:**
  - Страница **книги** — настроено (и для людей, и для ботов).
  - **Главная** и **каталог** — для ботов есть title и description; для людей в браузере вкладка всё ещё просто «FanVers».
  - **Главы**, профиль, поиск и остальное — для поисковиков **почти пусто** (бот видит пустой React).
- Отдельного «лого FanVers для Google» в настройках **нет**.

### Можно ли сделать?

**Да**, по частям:

| Часть | Сложность |
|-------|-----------|
| Иконка в выдаче | Легко — сделать favicon (раздел 1) |
| Текст в выдаче для книг | Уже работает |
| Текст для глав | Средне — нужен бэкенд + фронтенд (см. раздел 4) |
| Красивая «карточка организации» в Google | Сложно, не обязательно на старте |

### Варианты

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| **A. Только favicon** | Мало работы, Google подхватит за дни/недели | Только иконка, не весь брендинг |
| **B. Favicon + title на главных страницах через React** | У людей нормальная вкладка на главной/каталоге | Поисковикам всё равно нужен бэкенд для глав |
| **C. Полный SEO для глав** (бэкенд-шаблон + Helmet) | И люди, и Google видят правильный текст | Больше кода, как для книг |

### Где и как делать

**Иконка в Google:**
1. Сделать раздел 1 (favicon).
2. Зайти в [Google Search Console](https://search.google.com/search-console) → свой сайт `fan-vers.com`.
3. Подождать переобход (дни–недели). Ускорить: «Проверка URL» → «Запросить индексирование» для главной.

**Текст в выдаче (книги) — уже есть:**
- Бэкенд: `backend/apps/seo/templates/seo/book_detail.html`, `backend/apps/seo/constants.py`
- Фронтенд: `frontend/src/seo/BookSeoHelmet.tsx`, `frontend/src/seo/bookSeo.ts`
- Менять фразы — **в двух местах сразу**: `constants.py` и `bookSeo.ts` (чтобы текст совпадал).

**Текст для глав — пока нет, см. раздел 4.**

### Что нужно для починки

- Favicon (раздел 1)
- Доступ к Search Console и Bing Webmaster (уже настроены по документации)
- Для глав — отдельная задача на бэкенде

## 3. Карточка ссылки в Telegram, Instagram, Facebook и т.д.

Когда кидаешь ссылку — появляется блок: картинка, заголовок, описание.

### Состояние сейчас

| Какую ссылку кидают | Карточка |
|---------------------|----------|
| `fan-vers.com/books/название-книги/` | **Работает**, если у книги есть обложка |
| `fan-vers.com/` (главная) | **Плохо** — нет картинки и нормального заголовка для бота |
| `fan-vers.com/catalog/` | **Плохо** — то же |
| `fan-vers.com/books/.../chapters/.../` (глава) | **Не работает** — бот видит пустую страницу |
| Профиль, поиск, чат и др. | **Не работает** |

**Почему книга работает:** Django отдаёт боту HTML с заголовком, описанием и ссылкой на обложку из базы (`/media/...`).

**Почему главная не работает:** шаблон `backend/apps/seo/templates/seo/home.html` не содержит тегов для превью (картинка, тип страницы).

### Можно ли сделать?

**Да** для каждого типа страницы отдельно.

### Варианты — главная и каталог

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| **A. Одна картинка-заглушка для всего сайта** | Быстро, один раз нарисовать 1200×630 px | Все ссылки без книги выглядят одинаково |
| **B. Разные картинки для главной и каталога** | Чуть точнее | Две картинки + правки двух шаблонов |
| **C. Автогенерация картинки под каждую книгу (Pillow)** | Идеальные пропорции, текст на картинке | Много работы, отложено в планах |

### Где и как делать — главная

1. **Нарисовать картинку** 1200×630 px: логотип FanVers + короткий слоган. Сохранить как `frontend/public/link-preview-default.png` (или любое имя, главное — запомнить путь).
2. **Открыть** `backend/apps/seo/templates/seo/home.html`.
3. **Добавить блок** (по образцу `book_detail.html`, блок `extra_meta`) с полями:
   - заголовок = `{{ seo_title }}`
   - описание = `{{ seo_meta_description }}`
   - картинка = `https://fan-vers.com/link-preview-default.png` (или через `{{ site_url }}/link-preview-default.png`)
   - тип страницы = «website»
4. **То же для** `backend/apps/seo/templates/seo/catalog.html` (можно ту же картинку).
5. **Задеплоить** фронт (картинка) + бэкенд (шаблоны).
6. **Проверить:**
   - Telegram: отправить ссылку себе в «Избранное».
   - Facebook: [developers.facebook.com/tools/debug](https://developers.facebook.com/tools/debug/) → вставить URL → «Scrape Again».

### Варианты — страница книги (уже работает, но можно улучшить)

| Проблема | Решение |
|----------|---------|
| Нет обложки у книги | Карточка без картинки — добавить заглушку в `book_detail.html` (если нет `og_image`, подставить default) |
| Обложка узкая/не 1200×630 | Пока ок для Telegram; позже — автогенерация на бэкенде |
| На dev картинка не грузится | На проде должно работать; dev для превью не важен |

**Файлы книги:**
- Бэкенд: `backend/apps/seo/templates/seo/book_detail.html`, `backend/apps/seo/utils.py` (поле `og_image`)
- Фронтенд (для браузера, не для Telegram): `frontend/src/seo/BookSeoHelmet.tsx`

### Что нужно для починки главной/каталога

- Картинка 1200×630 px
- Правка 2 шаблонов Django
- Деплой
- На сервере nginx должен пускать ботов на Django (уже описано в `nginx_seo.conf.example`)

## 4. Карточка ссылки на главу (чтение текста)

### Состояние сейчас

**Не работает.** URL вида `/books/книга/chapters/глава/` ботами не обрабатывается.

### Можно ли сделать?

**Да**, но это **самая большая** из задач здесь (несколько файлов + nginx).

### Что нужно сделать (по порядку)

1. **Бэкенд —** `backend/apps/seo/middleware.py`: добавить маршрут для `/books/.../chapters/.../`.
2. **Бэкенд —** создать шаблон `backend/apps/seo/templates/seo/chapter_detail.html` (заголовок главы, описание, картинка = обложка книги).
3. **Бэкенд —** `backend/apps/seo/utils.py`: функция контекста для главы.
4. **Nginx —** добавить chapter-URL в regex (файл-пример: `nginx_seo.conf.example`), применить на сервере, `sudo nginx -t`, перезагрузить nginx.
5. **Фронтенд —** компонент вроде `ChapterSeoHelmet.tsx` и подключить в `ChapterDetail.tsx` (чтобы у людей нормальная вкладка).
6. **Опционально —** добавить главы в `sitemap.xml` (`backend/apps/seo/views.py`).

Подробный пошаговый план уже есть в `frontend/src/docs/SEO_IMPLEMENTATION_PLAN.md` (Задача 1) — там технические детали, если понадобятся разработчику.

### Плюсы и минусы

| | |
|--|--|
| **+** | Тысячи страниц станут видны в Google и в превью ссылок |
| **−** | Много файлов, нужен аккуратный деплой, главы не трогать в модели Chapter |

## 6. Где что лежит (шпаргалка файлов)

```
frontend/
  index.html                          ← сюда favicon-ссылки
  public/                             ← сюда файлы иконок и картинка для превью
  src/assets/logos/logo.png           ← лого в шапке (НЕ favicon)
  src/seo/BookSeoHelmet.tsx           ← заголовок вкладки для книги (люди)
  src/seo/bookSeo.ts                  ← тексты для книги (люди)

backend/apps/seo/
  middleware.py                       ← кто бот и какие URL обрабатывать
  templates/seo/home.html             ← главная для ботов
  templates/seo/catalog.html          ← каталог для ботов
  templates/seo/book_detail.html      ← книга для ботов (+ превью ссылки)
  utils.py                            ← откуда берётся картинка обложки
  constants.py                        ← тексты «читать ранобе українською...»
  nginx_seo.conf.example              ← как настроить сервер для ботов
```

## 7. Как проверить, что починилось

| Что проверяем | Как |
|---------------|-----|
| Favicon | Открыть сайт, посмотреть вкладку. Ctrl+Shift+R |
| Превью книги | Кинуть ссылку на книгу в Telegram |
| Превью главной | Кинуть `https://fan-vers.com/` в Telegram |
| Что видит Google | Search Console → «Проверка URL» |
| Что видит Facebook/Instagram | [developers.facebook.com/tools/debug](https://developers.facebook.com/tools/debug/) |
| Что отдаёт сервер боту | В терминале: `curl -H "User-Agent: Googlebot" https://fan-vers.com/books/SLUG/` — в ответе должны быть `<title>`, описание и ссылка на картинку, а не `<div id="root">` |
