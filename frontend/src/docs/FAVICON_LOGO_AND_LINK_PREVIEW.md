Коротко: что ещё не сделано и как починить.

**Favicon (иконка вкладки) — уже готово:** файлы в `frontend/public/`, ссылки в `index.html`, `site.webmanifest`. После деплоя Google подхватит иконку сам (нужно время).

## Общая картина

Сайт — React-приложение. Браузер пользователя всё рисует сам.

Когда человек **кидает ссылку в Telegram, Instagram, Facebook** — тот сервис **не открывает сайт как браузер**. Он один раз скачивает HTML и ищет там заголовок, описание и картинку.

| Кто открывает | Что видит | Кто настраивает |
|---------------|-----------|-----------------|
| Человек в Chrome/Firefox | React + вкладка с названием | Фронтенд (`frontend/`) |
| Telegram, Google-бот, Facebook | HTML от Django | Бэкенд (`backend/apps/seo/`) |

**Важно:** на сервере (nginx) ботов нужно направлять на Django, иначе они получат пустую страницу. Пример: `backend/apps/seo/nginx_seo.conf.example`.

## 1. Лого / иконка сайта в Google и Bing

В результатах поиска слева от адреса — маленькая иконка. Под ней заголовок и текст.

### Состояние сейчас

- **Иконка в поиске:** favicon на сайте уже есть — Google подхватит после деплоя и переобхода (дни–недели). Ускорить: Search Console → «Проверка URL» → «Запросить индексирование» для главной.
- **Заголовок и описание:**
  - Страница **книги** — настроено (и для людей, и для ботов).
  - **Главная** и **каталог** — для ботов есть title и description; для людей в браузере вкладка всё ещё просто «FanVers».
  - **Главы**, профиль, поиск и остальное — для поисковиков **почти пусто** (бот видит пустой React).
- Отдельного «лого FanVers для Google» в настройках **нет**.

### Можно ли сделать?

**Да**, по частям:

| Часть | Сложность |
|-------|-----------|
| Иконка в выдаче | Уже настроена на сайте — ждать Google |
| Текст в выдаче для книг | Уже работает |
| Текст для глав | Средне — бэкенд + фронтенд (см. раздел 3) |
| «Карточка организации» в Google | Сложно, не обязательно на старте |

### Варианты (заголовки на главной/каталоге для людей)

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| **A. Title через React (Helmet)** | Нормальная вкладка у людей | Поисковикам всё равно нужен бэкенд |
| **B. Полный SEO для глав** (бэкенд + Helmet) | И люди, и Google видят правильный текст | Больше кода, как для книг |

### Где и как делать

**Иконка в Google:**
1. Задеплоить фронт с favicon (если ещё не на проде).
2. [Google Search Console](https://search.google.com/search-console) → `fan-vers.com` → дождаться переобхода.

**Текст в выдаче (книги) — уже есть:**
- Бэкенд: `backend/apps/seo/templates/seo/book_detail.html`, `backend/apps/seo/constants.py`
- Фронтенд: `frontend/src/seo/BookSeoHelmet.tsx`, `frontend/src/seo/bookSeo.ts`
- Менять фразы — **в двух местах сразу**: `constants.py` и `bookSeo.ts`.

**Текст для глав — см. раздел 3.**

## 2. Карточка ссылки в Telegram, Instagram, Facebook и т.д.

Когда кидаешь ссылку — блок: картинка, заголовок, описание.

### Состояние сейчас

| Какую ссылку кидают | Карточка |
|---------------------|----------|
| `fan-vers.com/books/название-книги/` | **Работает**, если у книги есть обложка |
| `fan-vers.com/` (главная) | **Плохо** — нет картинки и нормального заголовка для бота |
| `fan-vers.com/catalog/` | **Плохо** — то же |
| `fan-vers.com/books/.../chapters/.../` (глава) | **Не работает** — бот видит пустую страницу |
| Профиль, поиск, чат и др. | **Не работает** |

**Почему книга работает:** Django отдаёт боту HTML с заголовком, описанием и обложкой из базы (`/media/...`).

**Почему главная не работает:** `backend/apps/seo/templates/seo/home.html` не содержит тегов для превью.

### Варианты — главная и каталог

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| **A. Одна картинка-заглушка** | Быстро, 1200×630 px один раз | Все ссылки без книги одинаковые |
| **B. Разные картинки для главной и каталога** | Чуть точнее | Две картинки + два шаблона |
| **C. Автогенерация под каждую книгу** | Идеальные пропорции | Много работы, позже |

### Где и как делать — главная

1. **Нарисовать картинку** 1200×630 px: логотип + слоган → `frontend/public/link-preview-default.png`.
2. **Открыть** `backend/apps/seo/templates/seo/home.html`.
3. **Добавить блок** (по образцу `book_detail.html`, `extra_meta`): заголовок, описание, картинка `{{ site_url }}/link-preview-default.png`, тип «website».
4. **То же для** `backend/apps/seo/templates/seo/catalog.html`.
5. **Задеплоить** фронт + бэкенд.
6. **Проверить:** Telegram — ссылка в «Избранное»; Facebook — [developers.facebook.com/tools/debug](https://developers.facebook.com/tools/debug/) → «Scrape Again».

### Страница книги — уже работает, можно улучшить

| Проблема | Решение |
|----------|---------|
| Нет обложки | Заглушка в `book_detail.html`, если нет картинки |
| Обложка не 1200×630 | Пока ок для Telegram; позже автогенерация |
| Dev | Превью проверять на проде |

**Файлы:** `book_detail.html`, `utils.py` (бэкенд); `BookSeoHelmet.tsx` (фронт, для браузера).

## 3. Карточка ссылки на главу

### Состояние сейчас

**Не работает.** URL `/books/книга/chapters/глава/` ботами не обрабатывается.

### Что сделать (по порядку)

1. `backend/apps/seo/middleware.py` — маршрут для глав.

5. Фронт — `ChapterSeoHelmet.tsx` в `ChapterDetail.tsx`.
6. Опционально — главы в `sitemap.xml`.
